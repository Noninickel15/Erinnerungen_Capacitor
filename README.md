# Erinnerungsapp (Capacitor)

Eine einfache Capacitor-App zur Speicherung von Erinnerungen im Web Storage.

## Projektstruktur

- `package.json` - Node/Capacitor-Basis
- `src/` - Web-App-Quellen
- `www/` - gebaute Web-App für Capacitor

## Skripte

- `npm run build` - Kopiert die Web-App nach `www`
- `npm run sync` - Synchronisiert Capacitor-Plugins und native Projekte
- `npm run android` - Öffnet das Android-Projekt in Android Studio

## Hinweise

1. Führe `npm install` aus.
2. Baue die Web-App mit `npm run build`.
3. Synchronisiere mit Capacitor: `npm run sync`.
4. Öffne Android Studio mit `npm run android`.
